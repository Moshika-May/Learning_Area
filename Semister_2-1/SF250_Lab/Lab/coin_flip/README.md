# Coin Flip Simulation

โปรแกรมจำลองการโยนเหรียญด้วยภาษา C สำหรับวิชา Probability & Statistics
แสดงผลเป็นกราฟ ASCII และสถิติสรุปใน terminal

## Build & Run

```bash
gcc -O2 -o coin coin.c -lm
./coin [N] [p_head] [seed]
```

| อาร์กิวเมนต์ | ความหมาย | ค่าเริ่มต้น |
|---|---|---|
| `N` | จำนวนครั้งที่โยน (ต้อง >= 10) | 1000 |
| `p_head` | ความน่าจะเป็นที่ออกหัว (0 < p < 1) | 0.5 |
| `seed` | seed ของตัวสุ่ม (ใส่ค่าเดิมจะได้ผลซ้ำเดิม) | เวลาปัจจุบัน |

ตัวอย่าง:

```bash
./coin                    # 1000 ครั้ง เหรียญปกติ
./coin 100000 0.5 42      # 100,000 ครั้ง seed = 42
./coin 5000 0.7           # เหรียญเอนเอียง P(H) = 0.7
```

## Output

### 1. กราฟการลู่เข้า (Law of Large Numbers)
แสดงสัดส่วนหัวสะสม p̂ = heads / n ที่ 20 จุดตามสเกล log
- `*` คือ p̂ ณ จุดนั้น
- `|` คือ p จริง
- ยิ่ง n มาก `*` ยิ่งเข้าใกล้ `|`

### 2. ฮิสโตแกรมทวินาม
แบ่งการโยนเป็นกลุ่มละ 10 ครั้ง นับจำนวนหัวต่อกลุ่ม (k = 0..10)
แล้วเทียบจำนวนกลุ่มที่ได้จริง (`obs`) กับค่าคาดหวังจาก Binomial(10, p) (`expected`)
แท่ง `#` คือค่าที่ได้จริง

### 3. สถิติสรุป
- จำนวนหัว/ก้อย และ p̂
- ค่าคาดหวังของจำนวนหัว = np และ SD = √(np(1-p))
- z = (heads - np) / SD และ χ² (df = 1) = z² เทียบกับค่าวิกฤต 3.841
- ช่วงความเชื่อมั่น 95% ของ p: p̂ ± 1.96·√(p̂(1-p̂)/n)
- ผลทดสอบ H0: P(H) = p ที่ α = 0.05 (reject เมื่อ |z| >= 1.96)
