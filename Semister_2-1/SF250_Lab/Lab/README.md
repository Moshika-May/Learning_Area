## 1. `coin_flip`: จำลองการโยนเหรียญ

**คืออะไร:** โยนเหรียญ N ครั้ง (หัวออกด้วยความน่าจะเป็น p) แล้วสรุปผลเป็นกราฟและสถิติ

**ทำงานยังไง:**
1. โยนทีละครั้ง นับหัวสะสม แล้วพิมพ์ p̂ = heads/n ที่ 20 จุด เพื่อดูว่าค่าเข้าใกล้ p
2. แบ่งการโยนเป็นกลุ่มละ 10 ครั้ง นับจำนวนหัวต่อกลุ่ม แล้วเทียบกับ Binomial(10, p)
3. คำนวณ z = (heads − np) / √(np(1−p)) แล้วตัดสิน H0 ที่ |z| ≥ 1.96

| ส่วนของโปรแกรม | อ้างอิงสไลด์ |
|---|---|
| ความน่าจะเป็น = ความถี่ระยะยาว (กราฟ p̂ ลู่เข้า p) | PF 5 |
| เหรียญหนึ่งครั้ง = Bernoulli, mean = p, var = p(1−p) | DD 4-5 |
| จำนวนหัวต่อ 10 ครั้ง = Binomial, pmf = nCr·p^r·(1−p)^(n−r) | DD 7 (กราฟ DD 10) |
| nCr คืออะไร | DD 8 |
| E[X] = np และ Var = np(1−p) | DD 11-12 |
| ประมาณ Binomial ด้วย Gaussian แล้วแปลงเป็นค่ามาตรฐาน z | TS 5, CD 9 |
| สมมติฐานว่าง H0, "ค่าที่สังเกตหรือสุดโต่งกว่านั้น" | TS 3-4, 7 |
| ทดสอบสองด้านกับเหรียญ (เหรียญยุติธรรมไหม) | TS 8 |
| ไม่ reject H0 ไม่ได้แปลว่า H0 จริง | TS 16 |
| ช่วง ±2σ ≈ 95% (ที่มาของเกณฑ์ |z| ≥ 1.96) | CD 11 |

ทุกส่วนอยู่ในสไลด์

## 2. `moment_generating_functions`: Moment Generating Function

**คืออะไร:** คำนวณ MGF สองวิธีแล้วเทียบกัน วิธีแรกใช้สูตรสำเร็จ วิธีที่สองคำนวณจากนิยามตรงๆ (ผลรวมหรืออินทิกรัล) ถ้าตรงกันแปลว่าสูตรถูก
ดูรายละเอียดการรันที่ `moment_generating_functions/README.md`

**ทำงานยังไง:** MGF เก็บโมเมนต์ทั้งหมดไว้ในฟังก์ชันเดียว หาค่าเฉลี่ยและความแปรปรวนได้จากอนุพันธ์ที่จุดอ้างอิง (ทำให้ไม่ต้องคำนวณผลรวมหรืออินทิกรัลยาวๆ)

| ส่วนของโปรแกรม | อ้างอิงสไลด์ |
|---|---|
| ทำไมต้องมี MGF (คำนวณ E[X] ของ Binomial ตรงๆ ยาวและน่าเบื่อ) | MGF 2 |
| MGF แบบไม่ต่อเนื่อง, E[R] = g'(1), E[R²] = g''(1) + g'(1) | MGF 3 |
| Binomial: g(z) = (q + pz)ⁿ ได้ E = np, Var = npq | MGF 4 |
| ตาราง Bernoulli / Binomial / Poisson | MGF 5 |
| MGF แบบต่อเนื่อง g(s) = ∫e^(sx)·p(x)dx, E[X] = g'(0), E[X²] = g''(0) | MGF 8 |
| ตาราง Uniform / Exponential / Gaussian | MGF 9 |
| Var = E[X²] − E[X]² | DD 6 |

หมายเหตุสัญลักษณ์: สไลด์เขียน MGF แบบไม่ต่อเนื่องเป็น g(z) = Σ zʳ·p(r) แต่ lab ใช้ M(t) = E[e^(tX)] ซึ่งเป็นตัวเดียวกันเมื่อ z = eᵗ

⚠ **นอกสไลด์:** K(t) = log M(t) ที่ใช้เพื่อกัน overflow เมื่อ n ใหญ่มาก, การอินทิเกรตเชิงตัวเลขแบบ Simpson, และการหา mean/var ด้วย finite difference

## 3. `waiting_bus`: เวลารอรถประจำทาง

**คืออะไร:** รถมาเฉลี่ยทุก T นาที เทียบเวลารอเฉลี่ยของคนที่มาถึงป้ายแบบสุ่ม ในสองกรณี
(1) รถมาตรงเวลาสม่ำเสมอ (2) รถมาแบบสุ่ม (Poisson)

**ทำงานยังไง:** สุ่มเวลารอ n ครั้งต่อกรณี กรณี 1 ใช้ `T·u` (Uniform[0,T]) กรณี 2 ใช้ `−T·ln(u)` (Exponential) แล้ววาดฮิสโตแกรมและเทียบค่าเฉลี่ยกับทฤษฎี T/2 กับ T
คำตอบที่น่าแปลกคือ อัตรามาเท่ากันแต่เวลารอเฉลี่ยต่างกัน 2 เท่า

| ส่วนของโปรแกรม | อ้างอิงสไลด์ |
|---|---|
| โจทย์นี้ตรงๆ (รถทุก 15 นาที, Uniform ได้ 7.5 กับ Exponential ได้ 15) | CM 2 |
| รถมาแบบสุ่ม = Poisson | DD 13-15 |
| เวลาระหว่างเหตุการณ์ Poisson = Exponential, ที่มาของ λe^(−λt) | CD 6-7 |
| mean = 1/λ, var = 1/λ² | CD 8 |
| `−T·ln(u)` สร้าง Exponential จาก Uniform (y = −log x ได้ Ex(1)) | CM 15-16 |
| คูณด้วย T เพื่อเปลี่ยนหน่วยเวลา (Jacobian) | CM 12 |

ทุกส่วนอยู่ในสไลด์

## 4. `binomial_poisson`: ประมาณ Binomial ด้วย Poisson

**คืออะไร:** เมื่อ n มากและ p น้อย Binomial B(n, p) จะใกล้เคียง Poisson Po(np) lab นี้จำลองแล้วเทียบ pmf ทั้งสองแบบ
รัน: `./binomial_poisson [n=100] [p=0.05] [samples=100000] [seed]`

**ทำงานยังไง:**
1. จำลองการทดลอง Bernoulli n ครั้ง นับจำนวนสำเร็จ ทำซ้ำ `samples` รอบ
2. พิมพ์ความถี่ที่ได้จริง เทียบกับ pmf ของ Binomial และ Poisson (λ = np) ที่แต่ละ r พร้อมแท่งกราฟ
3. เทียบ mean และ var กับทฤษฎี และรายงานผลต่างรวมของ pmf สองแบบ
4. ลอง `./binomial_poisson 100 0.05` (ใกล้กันมาก) เทียบกับ `./binomial_poisson 10 0.5` (ต่างกันชัด) เพื่อดูว่ากฎ n > 50, p < 0.1 มีความหมายอย่างไร

| ส่วนของโปรแกรม | อ้างอิงสไลด์ |
|---|---|
| Binomial: จำนวนสำเร็จใน n ครั้ง, pmf = nCr·p^r·(1−p)^(n−r) | DD 7 |
| nCr และปัญหา n! ใหญ่เกินไป | DD 8 |
| ตัวอย่าง CPU เสียบน wafer (n=100, p=0.05) ซึ่งเป็นค่าเริ่มต้นของ lab | DD 9 |
| กราฟ Binomial ที่พารามิเตอร์ต่างๆ | DD 10 |
| E[X] = np, Var = np(1−p) | DD 11-12 |
| ที่มาของ Poisson: แบ่งเวลาเป็นช่วงเล็กๆ แต่ละช่วงเป็น Bernoulli, p = λ/n, n → ∞ | DD 13-14 |
| Poisson pmf = λʳe^(−λ)/r!, E = Var = λ | DD 15 |
| กราฟ Poisson และการประมาณ B(n,p) ≈ Po(np) เมื่อ n > 50, p < 0.1 | DD 16 |

⚠ **นอกสไลด์:** การใช้ `lgamma` คำนวณแฟกทอเรียลใน log-space (สไลด์ DD 8 แนะนำ Stirling สำหรับปัญหาเดียวกัน) และตัวชี้วัดผลต่างรวม Σ|Binomial − Poisson|

## 5. `central_limit_theorem`: Central Limit Theorem

**คืออะไร:** แสดงว่าค่าเฉลี่ยของตัวอย่างจากประชากรที่ไม่ใช่ Normal จะมีการแจกแจงใกล้ Normal เมื่อ n มากขึ้น

**ทำงานยังไง:**
1. เลือกประชากร Uniform(0,1) หรือ Exp(1) แล้วสุ่ม n ตัว หาค่าเฉลี่ย ทำซ้ำ `reps` รอบ
2. แปลงแต่ละค่าเฉลี่ยเป็น z = (x̄ − μ) / (σ/√n)
3. วาดฮิสโตแกรมของ z เทียบกับจำนวนที่คาดไว้จาก N(0,1) และพิมพ์ mean, var, skewness
ลอง `./central_limit_theorem exp 1`, `exp 5`, `exp 30`, `exp 200` จะเห็นความเบ้ค่อยๆ หายไป

| ส่วนของโปรแกรม | อ้างอิงสไลด์ |
|---|---|
| ทฤษฎีบทขีดจำกัดกลาง: ΣXᵢ ~ N(nμ, nσ²) และ (ΣXᵢ − nμ)/(σ√n) ~ N(0,1) | MGF 15 |
| ตัวอย่างเดียวกันกับ lab: Yᵢ ~ Ex(1) ที่ n = 1, 2, 3, 5, 10 | MGF 16 |
| ผลรวมแล้ว "เป็น Gaussian มากขึ้น" | CM 10 |
| ค่าเฉลี่ยบวกกัน ความแปรปรวนบวกกัน (ตัวแปรอิสระ) | DD 12, CM 8 |
| Uniform(0,1) มี mean 1/2, var 1/12 | CM 8 |
| Exp(1) มี mean 1/λ, var 1/λ² | CD 8 |
| สุ่ม Exp ด้วย `−ln(u)` | CM 15 |
| แปลงเป็นค่ามาตรฐาน (x − μ)/σ | CD 9, CM 14 |
| ความน่าจะเป็นต่อช่วงใช้ Φ (ไม่มีรูปปิด) | CD 10-11 |
| skewness = E[(X−μ)³]/σ³, บวก = เบ้ขวา | CD 14-15 |

⚠ **นอกสไลด์:** ค่าทฤษฎีของ skewness (Exp(1) มี skewness = 2 และ skewness ของค่าเฉลี่ยลดลงตาม 2/√n)
