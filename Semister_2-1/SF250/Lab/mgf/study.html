1. The one idea

A random variable X is a number you don't know yet: a die roll, the number of emails you get today, the waiting time for a bus. A distribution says how likely each value is.

The average (expected value) of something g(X) is written E[g(X)]: each possible value times its probability, added up.

The moment generating function is just one particular average:

M(t) = E[ e^(t·X) ]

For each value of the dial t, you average the number e^(t·X). That is all it is. Different t gives a different average, so M is a function of t.

What does the dial t do?

e^(t·x) is a weight placed on each value x.

  • t = 0: e^0 = 1 for everything. No favourites. So M(0) = 1 always (probabilities add to 1).
  • t > 0: big x get a big weight. The average is dominated by the right side of the distribution.
  • t < 0: big x get squashed, small x dominate. The average is dominated by the left side.

So think of t as a tilt: positive tilts the distribution toward the right, negative toward the left. M(t) is the total after tilting.

3. Why bother? The name "moment generating"

The moments of X are E[X] (mean), E[X²], E[X³], ... Variance comes from the first two: Var(X) = E[X²] − E[X]².

Expand the weight as a power series:

e^(tX) = 1 + t·X + t²·X²/2 + t³·X³/6 + ... M(t) = 1 + t·E[X] + t²·E[X²]/2 + t³·E[X³]/6 + ...

Every moment is sitting inside M(t) as a coefficient. To pull one out, take derivatives at t = 0:

M'(0) = E[X] (the mean) M''(0) = E[X²] (so Var = M''(0) − M'(0)²)

Worked example: Bernoulli(p)

X is 1 with probability p and 0 otherwise (a biased coin flip).

M(t) = (1−p)·e^(t·0) + p·e^(t·1) = 1 − p + p·e^t M'(t) = p·e^t → M'(0) = p → mean = p M''(t)= p·e^t → M''(0) = p → E[X²] = p Var = p − p² = p(1−p)

You never had to sum over outcomes again. Differentiate, plug in 0.

The log version, K(t)

K(t) = log M(t) is called the cumulant function. Even easier:

K'(0) = mean K''(0) = variance

The C programs use K because for large n, M(t) is a monstrous number (like e^360,000,000) that a computer cannot store, while K(t) is a normal-sized number.

Bonus superpower. If X and Y are independent, then MX+Y(t) = MX(t) · MY(t). Adding random variables becomes multiplying functions. That is how the Binomial is built below.

4. The discrete trio

"Discrete" means X takes separate values (0, 1, 2, ...). The average is a sum: M(t) = Σ e^(t·k) · P(X=k). The table in the playground shows exactly this sum, term by term.

Bernoulli(p) one coin flip

M(t) = 1 − p + p·e^t mean p variance p(1−p)

Binomial(n, p) n coin flips, count the heads

X = (flip 1) + (flip 2) + ... + (flip n), all independent Bernoulli. Multiply n copies of the Bernoulli MGF:

M(t) = (1 − p + p·e^t)^n mean n·p variance n·p·(1−p)

Check with the derivative: M'(t) = n(1−p+pe^t)^(n−1)·p·e^t, and at t = 0 the bracket is 1, so M'(0) = n·p.

Poisson(λ) counting rare events: emails per hour

Start from the definition and use the series e^z = Σ z^k / k!:

M(t) = Σ e^(t·k) · e^(−λ) · λ^k / k! = e^(−λ) · Σ (λ·e^t)^k / k! = e^(−λ) · e^(λ·e^t) = exp( λ·(e^t − 1) ) mean λ variance λ

5. The continuous trio

"Continuous" means X can be any real number in a range. The sum becomes an integral (area under a curve). In Picture B, M(t) is literally the shaded area.

M(t) = ∫ e^(t·x) · f(x) dx (f is the density, the curve in Picture A)

Uniform(a, b) every value in [a,b] equally likely

M(t) = (e^(t·b) − e^(t·a)) / (t·(b − a)) (and M(0) = 1) mean (a+b)/2 variance (b−a)²/12

Comes from integrating e^(tx)/(b−a) over [a, b].

Exponential(λ) waiting times

M(t) = ∫₀^∞ λ·e^(−λx)·e^(t·x) dx = λ / (λ − t) only when t < λ mean 1/λ variance 1/λ²

The exponent is −(λ−t)x. If t ≥ λ it does not decay and the area is infinite: the MGF only exists on part of the t-line. That is real and worth remembering.

Gaussian(μ, σ) the bell curve

M(t) = exp( μ·t + σ²·t²/2 ) mean μ variance σ²

Complete the square in the exponent and the integral collapses to this. Notice log M is a parabola, with slope μ at 0 and bend σ². Nothing else (no higher terms) is needed to describe a Gaussian.

7. Self-check

Try to answer before opening each one.

Why is M(0) always 1?

At t = 0 the weight e^(0·x) is 1 for every x, so you are averaging the number 1, which is 1.

X is Poisson with λ = 3. What is E[X] using the MGF?

M(t) = exp(3(e^t − 1)). M'(t) = 3e^t·M(t). At t = 0: 3·1·1 = 3.

Picture C for Binomial(10, 0.4): the slope at t = 0 should be?

The mean n·p = 4 (for log M; for M itself the slope is also 4, since M(0) = 1).

Why does the Exponential MGF stop at t = λ?

The integrand becomes e^(−(λ−t)x). When t ≥ λ it no longer shrinks as x grows, so the area is infinite.

Why does the Binomial MGF equal the Bernoulli MGF to the power n?

A binomial is a sum of n independent Bernoulli variables, and for independent variables the MGF of the sum is the product of the MGFs.

Two different distributions with the same MGF near t = 0: possible?

No. If the MGF exists around 0, it identifies the distribution uniquely. That is why MGFs are used to prove things like "a sum of Gaussians is Gaussian".

Glossary

Random variable (X)
A number whose value is not known yet.
pmf
Probability mass function: P(X = k) for discrete X.
pdf
Probability density function f(x) for continuous X. Areas under it are probabilities.
E[...] expected value
The probability-weighted average.
Moment
E[X], E[X²], E[X³]... The first is the mean; the first two give the variance.
MGF, M(t)
E[e^(tX)].
K(t)
log M(t). K'(0) is the mean, K''(0) is the variance.
Independent
Knowing one tells you nothing about the other.
